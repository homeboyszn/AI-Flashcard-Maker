🎴 AI Flashcard MakerAn intelligent, web-based flashcard generator powered by Gemini Structured Outputs (responseSchema) and built with client-side SuperMemo (SM-2) Spaced Repetition review scheduling.Convert raw lecture notes, articles, or complex concept sheets into structured, categorized flashcard decks instantly.✨ Features🧠 Gemini API Integration: Powered by Google's Gemini models using strict JSON schema enforcement (responseSchema) to extract concise, high-quality Q&A pairs.🎯 Dynamic Deck Generation: Automatically generates thorough flashcards covering definitions, core concepts, and factual details from your notes.🏷️ Auto-Tagging & Categories: Automatically classifies each card by topic category and assigns difficulty levels (Easy, Medium, Hard).⏱️ SM-2 Spaced Repetition Engine: Review cards with Again, Good, or Easy ratings. Tracks review counts, calculates optimal intervals, and schedules due dates.🔍 Category Filter Bar: Filter cards dynamically by topic chips to study specific sub-subjects independently.🔊 Text-to-Speech (TTS): Integrated Web Speech API allows you to listen to card answers for audio learning.📥 Export to Anki CSV: One-click CSV export pre-formatted for seamless import into Anki and other study tools.💾 LocalStorage Persistence: Automatically saves generated decks, study progress, and review dates locally in your browser.⚡ Zero Backend Required: Completely client-side application using vanilla HTML, CSS, and JavaScript.🚀 Quick Start1. 🧠 Spaced Repetition Algorithm (SM-2)The app schedules reviews using the SuperMemo SM-2 algorithm:RatingQuality (q)BehaviorAgain1Resets review interval ($I = 1$ day) and repetition count ($n = 0$).Good3Increments interval ($I_n = I_{n-1} \times \text{EF}$) and repetition count.Easy5Increments interval and increases the card's Easiness Factor ($\text{EF}$).$$EF' = EF + (0.1 - (5 - q) \times (0.08 + (5 - q) \times 0.02))$$(Minimum Easiness Factor is capped at 1.3)🌐 Deploying to GitHub PagesYou can host this project live on the web for free via GitHub Pages:Push your repository to GitHub (https://github.com/homeboyszn/ai-flashcard-maker).Go to Settings > Pages in your repository.Under Build and deployment > Branch, select main and / (root).Click Save.Your app will be live at:
